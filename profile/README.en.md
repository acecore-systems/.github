# Acecore

[← Choose another language](README.md)

Acecore supports businesses, learning, and communities through technology and education. This GitHub organization shares implementations of websites and community tools, shared foundations, and public design documents.

[Official website](https://acecore.net/en/) · [Business directory](https://acecore.net/en/services/) · [Contact](https://acecore.net/en/contact/)

## Services

- [Acecore Systems](https://systems.acecore.net/) — Business systems, web apps, websites, operations, and IT advisory.
- [Acecore Schools](https://schools.acecore.net/) — IT education and learning support.
- [Aceserver](https://asv.acecore.net/) — A Minecraft community operated by Acecore.
- [Acecore Store](https://store.acecore.net/) — The official online store for Acecore and Aceserver.

The service websites have the latest details and instructions for using them.

## Public repositories

### Websites and community

- [acecore-net](https://github.com/acecore-systems/acecore-net) — Acecore's corporate website and technical blog.
- [acecore-systems](https://github.com/acecore-systems/acecore-systems) — The Acecore Systems site, including services, project examples, and technical articles.
- [acecore-schools](https://github.com/acecore-systems/acecore-schools) — The Acecore Schools website and booking and member portal.
- [aceserver-portal](https://github.com/acecore-systems/aceserver-portal) — The Aceserver community portal.
- [aceserver-wiki](https://github.com/acecore-systems/aceserver-wiki) — The Aceserver wiki.
- [homepage-hatt](https://github.com/acecore-systems/homepage-hatt) — Hatt's official website.

### Shared foundations and design documents

- [cms-ai](https://github.com/acecore-systems/cms-ai) — Shared AI conversation, permissions, and pull request support for Sveltia CMS.
- [codex-task-routing](https://github.com/acecore-systems/codex-task-routing) — Policies for assigning Codex tasks and handing off work.
- [world-foundation](https://github.com/acecore-systems/world-foundation) — Public design documents for a cooperation framework that people can join, leave, or fork.
- [world-foundation-site](https://github.com/acecore-systems/world-foundation-site) — A site for browsing and searching those documents.
- [.github](https://github.com/acecore-systems/.github) — The organization profile and shared contribution and security guidance.

### Minecraft tools and assets

- [Aceguessr](https://github.com/acecore-systems/Aceguessr) — An Aceguessr plugin for Minecraft.
- [CommonModal](https://github.com/acecore-systems/CommonModal) — A plugin and mod for showing forms on a client from a server.
- [aceserver-minecraft-assets](https://github.com/acecore-systems/aceserver-minecraft-assets) — Minecraft assets distributed by Aceserver.
- [dynmap](https://github.com/acecore-systems/dynmap) — A fork of the Dynmap web mapping system for Minecraft.

Check each repository's license and asset guidance before using or redistributing its contents.

## Use and contribute

- **Report bugs or suggest improvements:** Read the repository's README and open an Issue there.
- **Contribute code or documentation:** Follow the repository's instructions and the [contribution guide](https://github.com/acecore-systems/.github/blob/main/CONTRIBUTING.md#english), then propose an Issue or pull request.
- **Discuss business or partnerships:** Use the [contact form](https://acecore.net/en/contact/).
- **Report a vulnerability:** Do not post it in a public Issue. Follow the repository's instructions or the [shared security policy](https://github.com/acecore-systems/.github/blob/main/SECURITY.md#english).
