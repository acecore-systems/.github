# Acecore

[← 选择其他语言](README.md)

Acecore 通过技术与教育支持企业、学习和社群。本 GitHub 组织公开网站与社区工具的实现、共用基础项目和设计文档。

[官方网站](https://acecore.net/zh-cn/) · [业务介绍](https://acecore.net/zh-cn/services/) · [联系我们](https://acecore.net/zh-cn/contact/)

## 业务与服务

- [Acecore Systems](https://systems.acecore.net/) — 业务系统、Web 应用、网站开发、运营支持和 IT 顾问服务。
- [Acecore Schools](https://schools.acecore.net/) — IT 教育与学习支持。
- [Aceserver](https://asv.acecore.net/) — Acecore 运营的 Minecraft 社群。
- [Acecore Store](https://store.acecore.net/) — Acecore 与 Aceserver 的官方在线商店。

服务内容和使用方法请以各官方网站的最新信息为准。

### Minecraft 工具与素材

## 使用与参与

- **报告问题或提出改进：** 先阅读对应仓库的 README，再在该仓库提交 Issue。
- **贡献代码或文档：** 按照对应仓库的说明和[贡献指南](https://github.com/acecore-systems/.github/blob/main/CONTRIBUTING.md)，通过 Issue 或拉取请求提出建议。
- **业务或合作咨询：** 使用[联系表单](https://acecore.net/zh-cn/contact/)。
- **报告安全漏洞：** 请勿在公开 Issue 中发布。请遵循对应仓库的说明或[共用安全政策](https://github.com/acecore-systems/.github/blob/main/SECURITY.md)。
