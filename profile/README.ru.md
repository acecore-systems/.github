# Acecore

[← Выбрать другой язык](README.md)

Acecore поддерживает бизнес, обучение и сообщества с помощью технологий и образования. В этой организации GitHub опубликованы реализации сайтов и инструментов для сообществ, общие компоненты и проектная документация.

[Официальный сайт](https://acecore.net/ru/) · [Направления работы](https://acecore.net/ru/services/) · [Контакты](https://acecore.net/ru/contact/)

## Направления и услуги

- [Acecore Systems](https://systems.acecore.net/) — Бизнес-системы, веб-приложения, сайты, сопровождение и ИТ-консультации.
- [Acecore Schools](https://schools.acecore.net/) — ИТ-образование и поддержка обучения.
- [Aceserver](https://asv.acecore.net/) — Сообщество Minecraft, которым управляет Acecore.
- [Acecore Store](https://store.acecore.net/) — Официальный интернет-магазин Acecore и Aceserver.

Актуальные сведения об услугах и порядке их использования размещены на соответствующих официальных сайтах.

## Публичные репозитории

### Сайты и сообщества

- [acecore-net](https://github.com/acecore-systems/acecore-net) — Корпоративный сайт и технический блог Acecore.
- [acecore-systems](https://github.com/acecore-systems/acecore-systems) — Сайт Acecore Systems с описанием услуг, примерами проектов и техническими статьями.
- [acecore-schools](https://github.com/acecore-systems/acecore-schools) — Сайт Acecore Schools, портал записи и личный кабинет.
- [aceserver-portal](https://github.com/acecore-systems/aceserver-portal) — Портал сообщества Aceserver.
- [aceserver-wiki](https://github.com/acecore-systems/aceserver-wiki) — Вики Aceserver.
- [homepage-hatt](https://github.com/acecore-systems/homepage-hatt) — Официальный сайт Hatt.

### Общие компоненты и проектная документация

- [cms-ai](https://github.com/acecore-systems/cms-ai) — Общая основа для диалогов с ИИ, управления правами и pull request в Sveltia CMS.
- [codex-task-routing](https://github.com/acecore-systems/codex-task-routing) — Правила распределения задач Codex и передачи работы.
- [world-foundation](https://github.com/acecore-systems/world-foundation) — Публичные проектные документы о системе сотрудничества с возможностью участия, выхода и создания ответвлений.
- [world-foundation-site](https://github.com/acecore-systems/world-foundation-site) — Сайт для просмотра и поиска по этим документам.
- [.github](https://github.com/acecore-systems/.github) — Профиль организации и общие правила участия и безопасности.

### Инструменты и материалы Minecraft

- [Aceguessr](https://github.com/acecore-systems/Aceguessr) — Плагин Aceguessr для Minecraft.
- [CommonModal](https://github.com/acecore-systems/CommonModal) — Плагин и мод для отображения форм с сервера на клиенте.
- [aceserver-minecraft-assets](https://github.com/acecore-systems/aceserver-minecraft-assets) — Материалы Minecraft, распространяемые Aceserver.
- [dynmap](https://github.com/acecore-systems/dynmap) — Форк системы веб-карт Dynmap для Minecraft.

Перед использованием или распространением материалов ознакомьтесь с лицензией и правилами для материалов в соответствующем репозитории.

## Использование и участие

- **Сообщить об ошибке или предложить улучшение:** Прочитайте README нужного репозитория и создайте Issue в нём.
- **Предложить код или документацию:** Следуйте инструкциям репозитория и [руководству для участников](https://github.com/acecore-systems/.github/blob/main/CONTRIBUTING.md), затем создайте Issue или pull request.
- **Обсудить проект или сотрудничество:** Используйте [контактную форму](https://acecore.net/ru/contact/).
- **Сообщить об уязвимости:** Не публикуйте её в открытом Issue. Следуйте инструкциям репозитория или [общей политике безопасности](https://github.com/acecore-systems/.github/blob/main/SECURITY.md).
