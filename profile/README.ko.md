# Acecore

[← 다른 언어 선택](README.md)

Acecore는 기술과 교육을 통해 사업, 학습, 커뮤니티를 지원합니다. 이 GitHub 조직에서는 웹사이트와 커뮤니티 도구의 구현, 공통 기반, 공개 설계 문서를 제공합니다.

[공식 사이트](https://acecore.net/ko/) · [사업 안내](https://acecore.net/ko/services/) · [문의하기](https://acecore.net/ko/contact/)

## 사업과 서비스

- [Acecore Systems](https://systems.acecore.net/) — 업무 시스템, 웹 앱, 웹사이트 개발, 운영 지원 및 IT 자문.
- [Acecore Schools](https://schools.acecore.net/) — IT 교육과 학습 지원.
- [Aceserver](https://asv.acecore.net/) — Acecore가 운영하는 Minecraft 커뮤니티.
- [Acecore Store](https://store.acecore.net/) — Acecore와 Aceserver의 공식 온라인 스토어.

서비스의 최신 내용과 이용 방법은 각 공식 사이트에서 확인해 주세요.
