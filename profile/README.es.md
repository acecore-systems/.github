# Acecore

[← Elegir otro idioma](README.md)

Acecore apoya a las empresas, el aprendizaje y las comunidades mediante la tecnología y la educación. En esta organización de GitHub publicamos implementaciones de sitios web y herramientas comunitarias, recursos compartidos y documentos de diseño.

[Sitio oficial](https://acecore.net/es/) · [Áreas de actividad](https://acecore.net/es/services/) · [Contacto](https://acecore.net/es/contact/)

## Actividades y servicios

- [Acecore Systems](https://systems.acecore.net/) — Sistemas de gestión, aplicaciones web, sitios web, operaciones y asesoría informática.
- [Acecore Schools](https://schools.acecore.net/) — Educación tecnológica y apoyo al aprendizaje.
- [Aceserver](https://asv.acecore.net/) — Una comunidad de Minecraft gestionada por Acecore.
- [Acecore Store](https://store.acecore.net/) — La tienda oficial en línea de Acecore y Aceserver.

Los sitios oficiales de cada servicio ofrecen los detalles y las instrucciones de uso más recientes.

- [cms-ai](https://github.com/acecore-systems/cms-ai) — Base compartida para conversaciones con IA, permisos y pull requests en Sveltia CMS.

## Uso y colaboración

- **Notificar errores o proponer mejoras:** Lee el README del repositorio correspondiente y abre allí un Issue.
- **Contribuir código o documentación:** Sigue las instrucciones del repositorio y la [guía de contribución](https://github.com/acecore-systems/.github/blob/main/CONTRIBUTING.md), y presenta tu propuesta mediante un Issue o pull request.
- **Consultas comerciales o de colaboración:** Usa el [formulario de contacto](https://acecore.net/es/contact/).
- **Informar de una vulnerabilidad:** No la publiques en un Issue público. Sigue las instrucciones del repositorio o la [política de seguridad compartida](https://github.com/acecore-systems/.github/blob/main/SECURITY.md).
