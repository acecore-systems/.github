# Acecore

[← Choisir une autre langue](README.md)

Acecore accompagne les entreprises, l’apprentissage et les communautés grâce à la technologie et à l’éducation. Cette organisation GitHub publie des sites et des outils communautaires, des ressources communes et des documents de conception.

[Site officiel](https://acecore.net/fr/) · [Activités](https://acecore.net/fr/services/) · [Contact](https://acecore.net/fr/contact/)

## Activités et services

- [Acecore Systems](https://systems.acecore.net/) — Systèmes de gestion, applications web, sites web, exploitation et conseil informatique.
- [Acecore Schools](https://schools.acecore.net/) — Formation informatique et accompagnement de l’apprentissage.
- [Aceserver](https://asv.acecore.net/) — Une communauté Minecraft gérée par Acecore.
- [Acecore Store](https://store.acecore.net/) — La boutique en ligne officielle d’Acecore et d’Aceserver.

Les sites officiels de chaque service présentent les informations et les modalités d’utilisation les plus récentes.

## Utiliser et contribuer

- **Signaler un problème ou proposer une amélioration :** Lisez le README du dépôt concerné, puis ouvrez une Issue dans ce dépôt.
- **Contribuer au code ou à la documentation :** Suivez les consignes du dépôt et le [guide de contribution](https://github.com/acecore-systems/.github/blob/main/CONTRIBUTING.md), puis proposez une Issue ou une pull request.
- **Contacter Acecore pour un projet ou un partenariat :** Utilisez le [formulaire de contact](https://acecore.net/fr/contact/).
- **Signaler une vulnérabilité :** Ne la publiez pas dans une Issue publique. Suivez les consignes du dépôt ou la [politique de sécurité commune](https://github.com/acecore-systems/.github/blob/main/SECURITY.md).
